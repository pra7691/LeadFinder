Fix Campaign Pipeline Run tracking and lead visibility structure.

Current issues:

1. When “Run Pipeline” is clicked, the Pipeline Runs section still says:
   “No pipeline runs yet. Trigger the pipeline manually above to get started.”
   This is wrong.

2. A campaign_run record is either not being created immediately, or the UI is not refreshing after creation.

3. There is no live run status showing while the campaign is running.

4. The campaign listing should show when a campaign is currently running.

5. Leads should be associated with Campaigns and Campaign Runs, not shown as a generic global Leads menu.

6. The left sidebar still has a “Leads” section. This should be removed or replaced because raw leads should be accessed from inside Campaigns/Runs. Curated leads should be accessed from Lists.

* started_at = current timestamp

* total_results = 0
* total_new_leads = 0

* total_blocked = 0
* total_rejected = 0

* completed_at
* final totals
