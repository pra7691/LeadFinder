Fix campaign execution terminology and simplify the run architecture.

Current issue:
The UI uses confusing terminology:

* Pause
* Run Pipeline
* Discovery
* Pipeline Runs
* Run Status

This product currently does NOT have automation pipelines yet.

Current workflow is manual:

* manually run campaign
* manually review leads
* manually add leads to lists
* manually prepare outreach

Therefore:
“Pipeline” terminology is incorrect and confusing.

The system should use simple terminology:

* Run Campaign
* Campaign Runs
* Current Run
* Run History

A “Campaign Run” simply means:
one execution of a campaign search/discovery process.

==================================================
PART 1 — TERMINOLOGY CLEANUP
============================

Rename throughout the app:

“Run Pipeline”
→ “Run Campaign”

“Pipeline Runs”
→ “Campaign Runs”

“Run Status”
→ “Current Run”

Remove:
“Discovery” button entirely.

Reason:
Discovery is already part of running a campaign.

==================================================
PART 2 — REMOVE PAUSE BUTTON
============================

Remove Pause/Resume controls for now.

Reason:
There is currently no true automation/scheduling workflow implemented.

Pause/Resume only makes sense later when:

* automated schedules
* followups
* recurring runs
* automation workflows
  exist.

Current product is manual-first.

==================================================
PART 3 — CAMPAIGN RUN CREATION
==============================

When user clicks “Run Campaign”:

Immediately create a campaign_runs entry before any search starts.

Set:

* campaign_id
* status = running
* run_type = manual
* started_at
* counters initialized to zero

Return campaign_run_id immediately.

All discovered leads must be linked to:

* campaign_id
* campaign_run_id

When completed:
update same campaign_runs record with:

* completed_at
* totals
* final status

PART 4 — CURRENT RUN SECTION
============================

Add a small “Current Run” section/card in Campaign Detail page.

Only show if:
status = running

Show:

* started time
* searches completed
* total results
* new leads
* blocked
* duplicates
* rejected
* latest activity

Auto-refresh every few seconds while active.

When run completes:
Current Run card disappears and run remains inside Campaign Runs history.
