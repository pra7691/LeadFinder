Refactor the lead organization structure by adding Campaign Runs and Lists.

Current issue:
All discovered leads are appearing together in the main Leads tab. This is confusing.

Required structure:

1. Campaigns define the search strategy.
2. Every time a campaign runs, create a Campaign Run entry.
3. Leads discovered during that run must be linked to that specific Campaign Run.
4. Lists are curated groups of selected leads.
5. Outreach/email should later happen only from Lists, not directly from raw leads.

Do not build email sending yet.
Do not remove existing leads.
Migrate existing data safely where possible.

==================================================
PART 1 — CAMPAIGN RUNS
======================

Add a campaign_runs table.

Fields:

* id
* campaign_id
* run_name nullable
* run_type
* status
* started_at
* completed_at
* total_searches
* total_results
* total_new_leads
* total_duplicates
* total_blocked
* total_rejected
* error_message
* metadata_json
* created_at

Run status values:

* running
* completed
* failed
* partial

Run type values:

* manual
* scheduled

Whenever a campaign discovery run starts:

* create a campaign_runs record
* attach all discovered leads to that run
* update run summary when completed

Add campaign_run_id to leads table.
