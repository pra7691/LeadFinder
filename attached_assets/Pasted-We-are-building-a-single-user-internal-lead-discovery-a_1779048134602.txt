We are building a single-user internal lead discovery and outreach tool.

Do not build the full product in one step. Start with the foundation only.

Product Goal:
Create a campaign-based lead intelligence system where I can create different campaigns for different services/products, search for companies using keywords and countries, crawl company websites, extract contact details, score relevance, manually approve leads, and later send outreach emails using Google Workspace SMTP.

Important:
This is a single-user internal tool for now. Do not add multi-user login, roles, billing, CRM integrations, or advanced analytics.

Tech Stack:

* Frontend: React + Tailwind
* Backend: Node.js + Express
* Database: PostgreSQL
* ORM: Drizzle or Prisma, whichever is more reliable in this project
* Search API later: Serper.dev
* Crawler later: fetch + Cheerio first, Playwright fallback later
* Email later: Google Workspace SMTP
* Export later: CSV/XLSX

Design Requirement:
Build a premium Apple-like glassmorphic UI.
