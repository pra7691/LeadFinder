Investigate why this project did not work immediately after importing/pulling from Git into a new Replit account, and make the setup reproducible so this does not happen again.

Do not add new product features.
Do not rebuild the app.
Focus only on import/setup/reproducibility.

Goal:
When this repository is imported into a fresh Replit account and the required secrets are added, the project should install, build, apply schema, and run without manual debugging.

==================================================
PART 1 — IDENTIFY WHAT WAS FIXED BY REPLIT
==========================================

Find out exactly what changed when Replit “made it work”.

Check:

* Git diff
* uncommitted files
* modified config files
* generated files
* package lock changes
* .replit changes
* artifact.toml changes
* workflow config changes
* build/run command changes
* database schema push
* dependency installation
* generated API client/Zod files
* environment/secrets assumptions
* Node/pnpm version setup

Run:

git status
git diff
git diff --staged

Also inspect:

* .replit
* replit.nix if present
* package.json
* pnpm-workspace.yaml
* pnpm-lock.yaml
* artifacts/api-server/.replit-artifact/artifact.toml
* artifacts/leadgen/.replit-artifact/artifact.toml
* lib/db/drizzle config
* deployment docs
* scripts folder

Report exactly:

1. What was missing after import.
2. What Replit changed automatically.
3. Which changes are committed vs uncommitted.
4. Which changes must be added to Git.
5. Which setup steps are account-specific and cannot be committed, such as Secrets.

==================================================
PART 2 — CHECK REQUIRED REPLIT SETUP
====================================

Verify a fresh Replit import needs:

* correct Node.js version
* pnpm installed/enforced
* pnpm install
* generated packages/codegen if required
* database schema push
* required secrets
* correct run command
* correct build command
* frontend/backend serving config
* health check working

Required secrets should be documented:

* DATABASE_URL
* PORT
* SESSION_SECRET
* SERPER_API_KEY
* NODE_ENV
* any other currently required secrets

OpenAI and SMTP should remain UI-configured unless current code requires otherwise.

==================================================
PART 3 — CREATE A REPRODUCIBLE SETUP SCRIPT
===========================================

Add a setup script if missing.

Create:

scripts/setup-replit.ts

or

scripts/setup-replit.sh

It should perform the safe setup steps needed after fresh import:

1. verify Node version
2. verify pnpm exists
3. run pnpm install if needed
4. run generated code/build prep if needed
5. verify required environment variables/secrets
6. push database schema:
   pnpm --filter @workspace/db run push
7. seed default settings if seed script exists
8. run deep health check or local diagnostic where possible
9. print clear success/failure messages

Do not expose secret values.

==================================================
PART 4 — ADD PACKAGE COMMANDS
=============================

Add root package.json scripts if missing:

setup:replit
db:push
seed:settings
smoke:test
health:deep if practical

Example:
pnpm run setup:replit

This should be the one command a developer runs after importing the repo into a fresh Replit.
