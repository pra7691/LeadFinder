Fix Campaign Run lifecycle and add blocked/skipped results visibility.

Current issue:
When a campaign run receives results from Serper, the run is marked Completed too early. This is wrong.

A Campaign Run should only be marked Completed after the full process is finished:
1. Serper search completed
2. results classified
3. blocked/skipped/duplicate results recorded
4. valid leads created
5. website crawling completed
6. extraction completed
7. relevance scoring completed
8. final counters/logs updated

Do not rebuild the app.
Do not change unrelated modules.
Preserve existing campaigns, runs, leads, lists, outreach data, and settings.

==================================================
PART 1 — FIX CAMPAIGN RUN STATUS LIFECYCLE
==================================================

Update Campaign Run status logic.

Correct lifecycle:

1. When Run Campaign is clicked:
status = running
stage = searching

2. While Serper/search is running:
stage = searching

3. After search results are received:
do NOT mark completed.
Move to:
stage = processing_results

4. While valid leads are being created:
stage = creating_leads

5. While websites are being crawled:
stage = crawling

6. While extraction is running:
stage = extracting

7. While scoring is running:
stage = scoring

8. Only after all stages finish:
status = completed
stage = completed
completed_at = current timestamp
duration_seconds calculated

If any stage fails but partial data exists:
status = partial
stage = failed_stage_name
error_message saved

If manually stopped:
status = cancelled
stage = cancelled
