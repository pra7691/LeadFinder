PART 8 — GLOBAL BLACKLIST BEHAVIOR
==================================

Global blocked domains must apply to all campaigns.

Before crawling or creating lead:

* normalize root domain
* check against global blocked domains
* if blocked, skip immediately
* do not crawl
* do not create lead
* log as blocked

Blocked domains should be managed from Settings.

Blacklist must support:

* exact domain match
* www normalization
* subdomain handling

Example:
If ycombinator.com is blocked:

* ycombinator.com skipped
* [www.ycombinator.com](http://www.ycombinator.com) skipped
* blog.ycombinator.com skipped
